let it search CDP docs\n\n---\n\n## Workflow Example\n\n### Scenario: Implementing /buy Command\n\n**Step 1: Setup**\n```\nAI: \"I need to implement /buy in my Telegram bot.\nSearch CDP docs for the wallet.createTrade() API.\"\n```\n\n**Step 2: Understand**\n```\nAI: \"Show me example code for buying ETH with USDC using CDP.\"\n```\n\n**Step 3: Error Handling**\n```\nAI: \"Search CDP docs for common trade errors and how to handle them.\"\n```\n\n**Step 4: Testing**\n```\nAI: \"How do I test trades on base-sepolia before production?\"\n```\n\n**Step 5: Optimize**\n```\nAI: \"Search CDP docs for best practices to make trades faster.\"\n```\n\n---\n\n## Quick Reference\n\n| Task | First Prompt |\n|------|-------------|\n| Add asset support | Prompt #13 |\n| Debug trade failure | Prompt #18, #19 |\n| Speed up bot | Prompt #21, #22, #23 |\n| Prepare for production | Prompt #24, #25 |\n| Add new feature | Prompts #27-32 |\n| Improve security | Prompt #9, #10, #11 |\n| Scale to 10k+ users | Prompt #16 |\n| Fix wallet issue | Prompt #3, #4, #5 |\n\n---\n\n## Resources\n\n- **[CDP MCP Setup](https://docs.cdp.coinbase.com/mcp)** — Connect your AI tool\n- **[CDP Documentation Index](https://docs.cdp.coinbase.com/llms.txt)** — Complete doc reference\n- **[CDP SDK Reference](https://docs.cdp.coinbase.com/)** — Official API docs\n- **[Telegram/Grammy Docs](https://grammy.dev/)** — Bot framework reference\n\n---\n\n**Happy prompting! 🚀**\n\nWith MCP connected, your AI tools are now CDP experts.
